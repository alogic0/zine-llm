# Learning Memory

Use this folder for reusable investigation, debugging, implementation, and
upstream-synchronization knowledge that is not yet stable reference material.

A useful learning tells future contributors what symptom they may see, what
the actual cause was, what to check first, and how the conclusion was verified.
Record incorrect LLM assumptions when explicitly naming the assumption will
prevent it from recurring.

Start with `docs/templates/learning-note.md`.
